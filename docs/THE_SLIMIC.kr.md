# The Slimic

[English](THE_SLIMIC.md) | 한국어 · [게임플레이](GAMEPLAY.kr.md) · [가이드북](GUIDEBOOK.kr.md)

[무너진 성채](FALLEN_SANCTUM.kr.md)는 왕국 지도 조각, 다섯 구역의 왕실 성역, 남아 있는 파수와 [왕실 융합](SYNTHESIS.kr.md)에 쓰이는 공용 왕실 융합 코어를 설명합니다.

The Slimic은 낡은 오버월드 같은 지형에 점액과 잊힌 슬라임 왕국의 흔적이 남은 별도 차원입니다. 하나의 바이옴인 **눅눅한 평원**이 구릉과 동굴, 물길 전체에 걸쳐 이어집니다. 일반적인 낮과 밤이 흐르며, 부활 장치는 오버월드 규칙을 따릅니다. 침대는 사용할 수 있고, 충전한 리스폰 정박기는 폭발합니다.

## 슬라임 차원문

오버월드에 **바닐라 슬라임 블록**으로 네더 차원문과 같은 세로 직사각형 틀을 만드세요. 내부 너비는 2~21칸, 높이는 3~21칸입니다. 최소 외곽 크기는 4×5칸, 최대는 23×23칸이며 네 모서리는 생략할 수 있습니다. 내부를 비우고 슬라임볼을 든 채 빈 공간을 향하는 틀 안쪽 면을 우클릭하세요. 생존 모드는 슬라임볼 하나를 소비하고, 크리에이티브 모드는 보존합니다. 양손 모두 사용할 수 있습니다.

생존 모드에서 안에 약 4초간 서 있으면 이동합니다. 크리에이티브 플레이어는 바로 이동합니다. 플레이어가 아닌 엔티티도 탑승 관계가 없으면 바로 이동합니다. 차원문은 오버월드와 The Slimic만 연결하며 **좌표 비율은 1:1**입니다. 탑승 중이라면 먼저 내리세요. 재이동 대기시간이 있으므로 차원문 밖으로 나온 뒤 다시 들어가야 합니다. 필수 틀 블록을 부수면 차원문이 닫히며, 틀을 수리한 뒤 다시 활성화할 수 있습니다.

도착 차원에서는 수평 128블록 안의 유효하고 안전한 차원문을 우선 사용합니다. 없다면 가까운 지형을 찾아 슬라임 블록 틀과 안전한 발판을 만들며, 필요하면 수면 위에도 발판을 놓습니다. 기존 보관함과 보호된 설치 구역은 보존합니다. 동료의 임시 조명은 차원문 활성화를 막지 않습니다. 안전한 출구를 만들 수 없다면 원래 차원에 남고, 플레이어에게 원인을 알립니다. 귀환용 차원문은 월드와 함께 저장됩니다.

## 눅눅한 평원

초록빛 Slimic 돌과 깊은 곳의 Slimic 점판암 위로 눅눅한 잔디, 흙, 미사, 점토, 진흙과 응고된 점액이 나타납니다. 지하에는 동굴과 익숙한 광물이 생성됩니다. 점액은 이동에 영향을 주므로 귀환용 차원문을 표시하고 일반 도구와 식량, 건축 자재를 준비하세요.

지표에는 야생 슬라임이, 평원에는 개구리가, 동굴에는 박쥐가 살아갑니다. 어두운 곳에는 익숙한 적대적 몹도 나타나며, 일반적인 난이도와 몹 생성 규칙이 적용됩니다. 가장 작은 야생 슬라임은 오버월드에서처럼 황금 사과로 길들일 수 있습니다.

## 장식

별도 **Slimic 장식** 크리에이티브 탭에는 **31종**이 있으며 조명·수정, 석재 장식·표지, 작업장 잔해·가구, 식물 순으로 정렬됩니다. 대부분의 고형 소품은 설치자를 향하고 단단한 윗면이 있는 바닥이 필요하며, 보이는 형태에 맞는 충돌 범위와 물을 머금는 기능이 있습니다. 바닥을 제거하면 소품을 드롭하고 내부의 물을 남깁니다. 식물은 적합한 흙이 필요합니다. 조명은 각 블록의 형태에 따라 빛을 내며, 잠든 봉화는 꺼져 있습니다.

### 장식 제작

다음 조합은 각각 **장식 1개**를 만듭니다. 배치에서 `/`는 줄 구분, `.`은 빈칸입니다. `P`는 점액이 밴 판자, `S`는 막대기, `W`는 초록색 양털, `C`는 작은 점액 수정 군집, `N`은 철 조각, `L`은 빛나는 슬라임입니다.

| 장식 | 재료 | 배치 |
| --- | --- | --- |
| 버려진 나무 상자 | 점액이 밴 판자 1개 + 막대기 1개 | 모양 없음 |
| 부서진 나무 상자 | 버려진 나무 상자 1개 | 모양 없음 |
| 부서진 작업대 | 점액이 밴 판자 2개 + 막대기 1개 | `PP / S.` |
| 폐허의 긴 의자 | 점액이 밴 판자 3개 + 막대기 2개 | `PPP / S.S` |
| 도구 걸이 | 점액이 밴 판자 3개 + 막대기 4개 | `S.S / PPP / S.S` |
| 오래된 슬라임 깃발 | 초록색 양털 4개 + 점액이 밴 판자 1개 + 막대기 1개 | `WW / WW / PS` |
| 작은 점액 수정 군집 | 빛나는 슬라임 1개 + 막대기 1개 | 모양 없음 |
| 점액 수정 군집 | 작은 점액 수정 군집 4개 | `CC / CC` |
| 점액 등불 | 철 조각 4개 + 빛나는 슬라임 1개 | `.N. / NLN / .N.` |

석재 장식은 기존 석재 절단기 조합법으로도 제작할 수 있습니다. 고대 화로와 장식 식물의 조합법도 JEI에서 확인할 수 있습니다.

## 폐허와 기록

평원 곳곳의 작업장·보급 거점·끊어진 길·기록 보관소·옛 왕도 유적은 현지 석재, 부서진 가구, 등불과 풍화된 이정표로 구성됩니다. 새로 생성되는 점거 유적에는 잊힌 왕국의 명령을 따르는 수호병·운반병과 일부 지휘관이 남아 있습니다. 고대 운반 슬라임은 연결된 슬라임 상자 사이에서 물자를 옮깁니다. 일반 상자에는 보급품과 번역된 기록이 있으며, 일정 확률로 인장 하나를 얻습니다.

고대 개체를 제압해 얻은 코어를 온전한 슬라임 복원 스테이션에서 복원하거나 인장으로 기존 전투 슬라임을 특화할 수 있습니다. 두 획득 경로와 보급 거점·기록 보관소·왕도 유적의 상세는 [잊혀진 명령](FORGOTTEN_ORDERS.kr.md)을 참고하세요. 고대 슬라임 상자를 열면 운반병의 연결이 해제됩니다. 온전한 받침대는 코어를 복원하며 다른 가구는 장식으로 남습니다. 기록은 돌아오지 않은 XXX와 끊어진 보급망, 마지막 수호 명령을 전합니다.

## 무너진 광산

무너진 광산은 The Slimic의 새 청크 중 건조하고 높이 차가 적은 지형에 나타납니다. 목재 입구와 버려진 장비, 지상으로 열린 굴착 구덩이가 진입로를 보여 줍니다. 기존 청크를 다시 생성하지 않습니다.

- **갱도형**은 내려가는 입구와 3×3 가로 통로로 구성되며, 지지대·돌무더기·거미줄과 파다 만 암벽이 남아 있습니다.
- **청크 굴착형**은 16×16 범위를 12~18칸 파낸 형태입니다. 채굴 슬라임과 같은 두 칸 너비의 둘레 계단과 미완성 아래층이 남아 있습니다. 계단 보호는 월드에 저장되며 이후 투입한 채굴 슬라임에도 적용됩니다.

광물화된 시체 블록은 부수면 손상된 코어 1개를 남깁니다. 광산 보급 상자의 오래된 명령 파편과 슬라임볼로 오버월드에서 고대 채굴·고대 터널 슬라임을 복원할 수 있습니다. 남아 있는 작업자와 폐광 수호 슬라임은 침입자를 공격합니다. 자세한 절차와 기존 빈 잔해의 차이는 [폐광 코어 복원](MINE_RECOVERY.kr.md)을 참고하세요. 슬라임볼로 시체를 직접 부활시킬 수는 없습니다. 플레이어 동료의 일반 부활은 그대로 유지됩니다.

생성 범위는 한 청크 안으로 제한하며, 물·용암·기존 블록 엔티티·파괴 불가 블록과 자연 지형이 아닌 건축 자재가 있으면 굴착 전에 제외합니다.

## 동료와 차원 이동

탑승하지 않은 동료는 슬라임 차원문으로 이동할 수 있습니다. UUID, 주인, 생명력, 기력, 능력치 강화, 장비와 화물을 유지하며, **모든 동료는 대기로 도착합니다.** 작업 거점은 직업별 재배치 규칙에 따라 조정됩니다. 채굴 슬라임은 새 차원에서 새로운 채굴 계획을 세웁니다. 슬라임 탐색기로 도착 지점을 확인한 뒤 명시적으로 작업을 시작하세요.

아이템으로 회수해 다른 차원에서 다시 소환할 수도 있습니다. 재소환은 대기로 시작하며 기존 [특성 보존 규칙](GAMEPLAY.kr.md#회수와-특성-유지)을 따릅니다. 공동 소유와 지휘 슬라임 개체 수 제한은 저장 세계의 모든 차원에 계속 적용됩니다.

## 버려진 집합실

새로 생성되는 눅눅한 평원에는 지상에서 보이는 계단과 지하 전투장을 갖춘 [버려진 집합실](AIMLESS_COLONY.kr.md)이 있습니다. 전투 진행도는 월드에 저장됩니다. 관찰 기록은 집합실의 과거를 전하며, 개인 보상으로 동료를 결속하고 다시 나누는 [군체 결속](COLONY_BONDING.kr.md)에 필요한 재료를 얻습니다. 기존 성채·폐광·옛 청크의 진행도와 지형은 유지합니다.
