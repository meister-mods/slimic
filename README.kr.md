# Slimic

[English](README.md) | 한국어

> 슬라임을 육성하고 일을 맡겨 조수로 활용하세요.

Slimic은 친근한 슬라임을 육성하고 일을 맡겨 조수로 활용하는 Minecraft Forge 모드입니다.

## 개요

자원 수집, 물자 운반, 농사와 벌목, 전투·조명·팀 관리·이동을 돕는 동료를 모아 함께 활동합니다. 각 슬라임은 서로의 작업을 지원합니다. 운반 슬라임은 동료의 화물을 수거하고 물품을 보급하며, 파발 슬라임은 작업을 진행할 수 없을 때 신호를 보냅니다.

동료는 활동과 능력치 강화로 성장합니다. 슬라임 조작기로 이름과 행동을 관리하고, 저장된 특성을 유지한 채 아이템으로 회수할 수 있습니다. 크리에이티브 슬라임 조작기는 능력치를 직접 편집하는 도구입니다. JEI는 조합법과 동료 안내를, Patchouli는 게임 내 가이드북을 선택적으로 제공합니다.

**The Slimic**의 눅눅한 지형과 버려진 작업장을 탐험하고, 무너진 광산의 고대 코어에서 새 동료를 복원하거나 왕국 지도를 따라 무너진 왕실 성역을 찾아 숙련된 채굴 동료들을 새 세대로 융합할 수 있습니다. 끝나지 않는 집합의 잔재에 맞서고, 같은 역할의 동료를 임시 군체로 결속했다가 다시 나눌 수도 있습니다. 고유한 건축 자재와 폐허 장식으로 거점도 꾸밀 수 있습니다.

Slimic은 `0.5.x` 범위의 초기 개발 단계입니다.

## 지원 환경

Minecraft **1.20.1**, Minecraft Forge **47.x**, Java **17**을 사용합니다.
