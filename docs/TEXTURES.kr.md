# 텍스처 편집

[English](TEXTURES.md) · [개발 가이드](DEVELOPMENT.kr.md#시각-에셋-규칙)

동료 장식은 [`assets/slimic/textures/entity/accessories`](../src/main/resources/assets/slimic/textures/entity/accessories)의 전용 PNG 아틀라스를 사용합니다. 리소스 팩의 같은 `assets/slimic/` 경로에 파일을 배치하면 개별 텍스처를 교체할 수 있습니다. PNG는 표면 무늬를, 클라이언트 모델은 형태·위치·애니메이션·장비 표시 조건을 정의합니다.

## UV 배치

[`texture-layouts.json`](texture-layouts.json)에 각 아틀라스의 모델 클래스와 직육면체 영역을 정리합니다. `uv`는 직육면체 영역 왼쪽 위의 논리 좌표이며, `size`는 모델 단위의 너비·높이·깊이입니다. `cube`는 해당 모델 부품 안에서 1부터 세는 직육면체 순번입니다. 반복되는 리라 현과 좌우 드래곤 날개는 각각 같은 UV 영역을 공유합니다.

시작점이 `(u, v)`, 크기가 `(w, h, d)`인 직육면체의 두 수평 면은 `(u+d, v, w, d)`와 `(u+d+w, v, w, d)`를 차지합니다. 네 수직 면은 `v+d`에서 시작하는 한 줄에 깊이 `d`, 너비 `w`, 깊이 `d`, 너비 `w` 순서로 놓이며 높이는 `h`입니다. 256×256 아틀라스에서는 이 좌표에 4를 곱하고, 64×64 안경 아틀라스에서는 그대로 사용합니다. 소수 크기를 사용하는 얇은 부품은 가장자리의 불투명 여백을 유지합니다.

표면 수정은 **F3+T**로 리소스를 다시 불러오면 반영됩니다. UV 배치·입체 형태·부착 위치를 바꿀 때는 해당 클라이언트 모델도 수정합니다. 채굴 램프와 수호 고리의 최대 밝기, 가죽 염색, 갑옷 마법 부여 광택은 렌더링 시 적용합니다.

## 실제 클라이언트 검증

준비된 클라이언트 스모크 월드에서 다음과 같이 실행합니다.

```sh
JAVA_TOOL_OPTIONS="-Dslimic.accessoryTexturesOnly=true" ./gradlew runClient -PclientSmoke=true
JAVA_TOOL_OPTIONS="-Dslimic.companionTooltipsOnly=true" ./gradlew runClient -PclientSmoke=true
JAVA_TOOL_OPTIONS="-Dslimic.visualPolishOnly=true" ./gradlew runClient -PclientSmoke=true
```

클라이언트 스모크 검증에 `-Dslimic.accessoryTexturesOnly=true`를 지정하면 불러온 PNG 크기와 Minecraft 모델의 실제 UV가 가리키는 면의 불투명도를 확인합니다. 이어서 모든 일반·군체 동료와 갑옷 외형 8종의 앞뒤 모습을 촬영하며, 가죽 염색·몸체 염색·마법 부여 광택·장착 도구·날개를 포함합니다. 임시 512×512 리소스 팩 교체와 원래 256×256 GPU 텍스처 복원도 확인합니다. `-Dslimic.textureReloadCycles=100`을 추가하면 교체·복원 주기를 반복해 장시간 재로딩을 검사합니다. 기존 `-Dslimic.inventoryLayoutOnly=true` 검증은 한국어·영어·일본어·스페인어의 동기화된 관리 화면 배치를 확인합니다. 이 옵션들은 개발 클라이언트의 설정된 실행 폴더에 `slimic-smoke`라는 월드가 미리 준비되어 있어야 합니다. 검증 중 인벤토리와 게임 모드를 바꾸므로 전용 검사 월드를 사용합니다.

시각 검증은 번역된 자재 탭, 간결한 장식 툴팁, 모든 월드 모델, 상자 아틀라스와 개폐, 바닐라 잔디 경계, 실제 GPU 아틀라스의 차원문 애니메이션 갱신을 확인합니다.

## 월드 자재

The Slimic은 [`assets/slimic/textures/block/world`](../src/main/resources/assets/slimic/textures/block/world)의 불투명한 **16×16** 자재 텍스처 8종과 애니메이션 차원문 스트립 1종을 사용합니다. 돌, 벽돌, 타일, 흙, 눅눅한 잔디, 미사, 응고된 점액, 대리석과 차원문 표면입니다. 픽셀 아트 원본을 최근접 보간으로 축소했으며, 차원문은 16×16 프레임 16장을 세로로 이은 **16×256** 이미지이며 알파를 보존합니다. `.png.mcmeta`는 3틱마다 다음 프레임으로 이동하고 프레임 사이를 보간하므로 이미지와 함께 유지하세요. 눅눅한 잔디는 전용 윗면·흙에 Minecraft의 불규칙한 잔디 옆면 오버레이를 겹칩니다.

`models/block/world`의 블록 모델은 이 텍스처 및 참조하는 Minecraft 표면과 색상 인덱스 0을 조합합니다. `SlimicWorldClient`가 목록에 정의된 색상을 블록과 아이템에 적용합니다. 계단·반 블록·담장, 잘라내기 식물, 반투명 유리와 차원문은 JSON에서 Forge 렌더 유형을 지정합니다. 리소스 팩으로 충돌 범위나 월드 생성 규칙을 바꾸지 않고 표면을 교체할 수 있습니다.

## 슬라임 상자

`textures/block/slime_chest.png`는 바닐라 단일 상자의 **64×64 UV 아틀라스** 배치를 따릅니다. 월드와 아이템 모델의 본체·뚜껑·걸쇠가 같은 파일을 공유합니다. 여러 면을 한 장에 배치하며 표면 1/16블록당 텍셀 1개의 바닐라 밀도를 유지합니다. 내부와 사용하지 않는 투명 영역을 유지하세요. `slime_chest_particle.png`는 파괴 입자의 표면입니다.

고대 명령 인장은 `assets/slimic/textures/item/ancient_command_seal.png`의 투명한 16×16 전용 텍스처를 사용합니다. 모서리를 깎은 금색 인장에 어두운 외곽선과 왼쪽 위의 밝은 테두리, 큼직한 보라색 나선 문양을 적용합니다. 모델은 한 레이어를 사용합니다. 적대 슬라임 생성 알은 바닐라 색상 적용 모델을 사용합니다.

고대 채굴·고대 터널 소환 모델은 `slime_summon_base`의 공통 금 블록 판을 상속하고 각각의 채굴·터널 코어 문장을 유지합니다. 안전모·수레·도구·문양은 기존 교체 가능한 텍스처를 사용합니다. 광물화 시체 모델은 망가진 슬라임 표면에 블록 모델 요소로 자수정 코어 면을 추가합니다. 코어와 명령 파편은 `assets/slimic/textures/item/`의 투명한 16×16 전용 스프라이트를 사용합니다. 코어 아이템 모델은 `slimic:ancient_core_role` 속성으로 역할별 외형을 선택합니다. 인장·코어·파편은 각각 최대 12색과 선명한 픽셀 경계를 사용해 바닐라 아이템과 해상도를 맞춥니다.

## 왕실 탐험과 융합

왕실 유물은 `textures/item`의 투명한 **16×16** PNG를 사용합니다. `kingdom_map_fragment`, `ancient_kingdom_map`, `royal_survey_compass`, `royal_courtyard_seal`, `royal_gallery_seal`, `royal_synthesis_core`는 제한된 팔레트와 서로 다른 윤곽·문양으로 구분합니다. 측량침의 아이템 모델 32종은 바닐라 나침반 속성으로 그림을 회전합니다.

차세대 채굴 소환 아이템은 공통 슬라임 바탕과 전용 `next_generation_mining_crest` 문장을 사용합니다. 채굴모의 왕실 융합 코어 문양은 헤드 랜턴을 피한 옆면에 표시합니다. 안전 안경은 전용 64×64 `prospecting_goggles` UV 아틀라스의 짙은 금속·철·청록 유리·가죽 영역을 사용합니다. 테는 불투명하며 렌즈는 얼굴 위에 반투명으로 표시합니다. 몸체와 부착 장비는 일반 동료의 75%로 함께 렌더링합니다. 길들인 고대 동료의 머리 표식은 계속 하얀색입니다. 융합 장치와 성채 중계대 모델은 왕실 아이템 그림과 금·석재 표면을 결합합니다. 목적지를 기록한 왕국 지도를 손에 들면 바닐라 지도 데이터·플레이어 표식·지도 렌더러를 사용합니다.

차세대 터널 슬라임은 작은 채굴모·안전 안경과 좁은 수레를 사용하고 소환 아이템은 공통 금 블록 판을 상속합니다. 전용 투명 16×16 `next_generation_tunnel_crest` 문장은 청록색 정사각형 굴을 둘러싼 은색 측정 도구와 초록 왕실 표식을 표현하며 불투명 색상은 최대 12색입니다.

## 집합실과 군체 에셋
