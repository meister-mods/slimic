# 군체 결속

[English](COLONY_BONDING.md) · [목적을 잃은 군체](AIMLESS_COLONY.kr.md) · [왕실 융합](SYNTHESIS.kr.md)

## 재사용 가능한 결속기 제작

**군체의 심장 1개, 철 주괴 2개, 슬라임볼 3개, 석재 벽돌 3개**로 군체 결속기를 만듭니다. 심장은 집합실 개인 첫 공략 보상, 평화로움 대안, 결속 파편 4개 조합으로 얻습니다. 완성한 결속기는 재사용하며, 묶거나 풀 때마다 심장을 추가로 소비하지 않습니다.

군체 결속은 원래 동료 둘을 보존하며 다시 해체할 수 있습니다. 왕실 융합은 일반 동료와 고대 동료를 소비해 새 동료를 만들며 되돌릴 수 없습니다. 두 과정은 각각 별도의 장치와 재료를 사용합니다.

## 동료 둘 결속하기

현재 **일반 운반 슬라임 두 마리** 또는 **일반 전투 슬라임 두 마리**를 지원합니다. 정확한 엔티티 유형이 같아야 하며, 상위 개체·다른 역할·서로 다른 역할·세 마리 이상은 지원하지 않습니다.

살아 있는 동료 둘을 회수해 결속기에 넣으세요. 둘 모두 본인이 원래 주인이어야 합니다. 장비와 화물을 지닌 채 넣을 수 있습니다. 상태 효과·흡수 생명력·화상·동결이 없고 호흡을 완전히 회복한 상태에서 결속합니다. 합산 생명력·기력이 지원하는 수치 범위를 넘으면 원본을 유지하고 결속을 거절합니다. 이미 활동·예약·결속 중이거나 손상되었거나 유효하지 않은 개체는 입력을 소비하지 않고 거절합니다. 지원하지 않는 외부 부착 데이터가 있으면 원본을 보존하고 결속을 거절합니다.

화면에서 두 이름, 현재 생명력·기력, 개별 미사용 포인트, 화물이 있는 가방 칸을 확인합니다. 군체의 최대 생명력·적재량·공격력·기력도 미리 표시합니다. 확인 후 **결속**을 누르면 저장된 대표 개체 하나를 인벤토리로 받습니다. 미수령 결과는 다른 결속기에서도 회수할 수 있습니다.

## 군체 운용

군체는 **동료 하나**로 관리하며 원래 두 구성원을 보존합니다. 결속 중에는 따로 소환할 수 없습니다. 처음 배치하거나 회수 후 배치하면 **대기**로 시작하고, 일반적인 월드 재접속에서는 기존의 명시적 명령을 유지합니다.

**운반 슬라임 군체**는 줄로 연결된 두 몸이 따로 움직입니다. 가방과 명령은 공유하며, 줄이 닿는 범위 안에서 화물 수거·적재·보급을 나누어 수행합니다. 같은 작업자나 보급품을 중복으로 예약하지 않도록 작업을 조율합니다. 어느 몸과 상호작용해도 군체 전체를 관리하며, 대기시키면 둘 다 멈춥니다. 전투 슬라임 군체는 기존처럼 붙어 있는 몸으로 이동하고 싸웁니다.

공용 미사용 포인트는 **결속 전 두 잔액의 산술평균에서 소수점 아래를 버린 값**으로 시작합니다. 예를 들어 2포인트와 5포인트를 가진 두 구성원은 공용 3포인트로 시작합니다. 각자 투자한 능력치는 그대로 유지합니다.

| 항목 | 동작 |
| --- | --- |
| 최대 생명력·최대 기력 | 지원하는 수치 범위 안에서 두 구성원의 값을 더합니다. |
| 현재 생명력·기력 | 실제 남은 총합입니다. 피해·치료·소모를 구성원 기록에도 반영합니다. |
| 화물 | 실제 적재량 둘을 더하며, 두 구성원의 실제 가방을 직접 사용합니다. 별도 복사본을 두지 않습니다. |
| 운반 보너스 | 일반 운반 슬라임의 적재량에 이미 포함되어 있으며 합산 후 다시 곱하지 않습니다. |
| 이동·작업 속도 | 두 구성원 중 낮은 값을 사용합니다. |
| 방어력·도달 거리·탐지 범위 | 두 구성원 값의 평균을 사용합니다. |
| 기본 공격력 | 개별 공격력 합계의 60%이며, 이후 실제 사용 무기의 기본 효과를 적용합니다. |
| 전투 장비 | 첫 입력 구성원의 검·방패·갑옷을 실제로 사용합니다. 내구도 소모와 교체도 그 구성원에게 반영하고 둘째 장비는 보관합니다. |
| 공격 대상 설정 | 군체 초기 설정은 첫 구성원을 따릅니다. 군체에서 바꿔도 원래 두 구성원의 개별 설정을 덮어쓰지 않습니다. |
| 성장 | 해당 역할에서 쓰는 능력치 중 둘 다 추가 강화할 수 있는 항목이 하나라도 남으면 활동 진행도를 절반만 반영합니다. 그런 항목이 없으면 기본 활동률을 적용하며, 두 구성원 모두 모든 능력치가 상한이어도 포인트를 계속 모을 수 있습니다. 요구량 공식은 기존과 같고 포인트는 공용으로 사용합니다. |
| 포인트 강화 | 공용 포인트 1개로 선택한 능력치의 상한에 도달하지 않은 구성원을 한 단계씩 강화합니다. 한쪽만 강화할 수 있으면 그쪽만 올리고 상한인 쪽은 유지합니다. 둘 다 상한이면 포인트를 소비하지 않습니다. 기존 투자는 초기화하지 않습니다. |
| 크리에이티브 조작 | 미사용 포인트만 편집하면 공용 잔액만 바꾸며 수정하지 않은 능력치와 적재량은 유지합니다. 능력치 직접 편집은 합산·평균 등 기존 산정 규칙에 따라 두 구성원에게 반영하며 생명력·기력·적재량은 합계로 다룹니다. |

어느 한 능력치가 상한이어도 다른 역할 능력치를 둘 다 강화할 수 있다면 성장률은 계속 절반입니다. 선택한 능력치를 둘 다 강화할 수 있을 때에는 같은 증가량을 적용하므로 기존 차이를 유지합니다.

두 구성원은 각자의 몸 색과 손 장비 외형을 유지합니다. 전투 군체의 두 몸에는 첫 구성원의 실제 갑옷을 같은 재질·염색·광택으로 표시하며, 둘째의 원래 갑옷은 해체할 때까지 보관합니다. 공통 동료 체계를 통해 추종·대기·작업·차원 이동·물류 지원·치료·회수·부활을 수행합니다. 운반 군체의 두 몸은 서로 일정 거리 안에 머물며 생명력과 기력을 함께 사용합니다. 전투 군체가 별도의 두 번째 공격을 수행하지는 않습니다.

회수하거나 해체해도 구성원의 생명력이나 기력이 회복되지는 않습니다. 대표 개체의 이름은 따로 바꿀 수 있고, 원래 구성원 이름은 해체할 때까지 보존합니다. 군체를 염색하거나 씻으면 첫 구성원의 색에도 반영합니다. 결속 후 군체에 새로 생긴 일시적 효과·흡수 생명력·화상·동결·호흡 상태는 남은 양과 시간 그대로 해체 시 첫 구성원에게 한 번 옮깁니다. 일시적으로 늘어난 생명력도 회수와 해체 과정에서 보존합니다.

## 안전하게 해체하기

군체를 회수해 **결속기 첫 칸에만** 넣고 두 기록을 확인한 뒤 **해체**를 누르세요. 주변에 불러와진 안전한 자리 둘이 필요하며, 단단한 바닥·충돌 여유·유체가 없는 공간을 확인합니다. 공간 부족, 소환 취소, 확정 전 저장 실패 시 군체를 유지합니다.

성공하면 원래 **동료 두 마리**가 가까이에 **대기** 상태로 돌아옵니다. 남은 생명력·기력·장비·화물·소유권·투자한 능력치·직업 설정을 유지합니다. 남은 공용 포인트는 두 구성원에게 그대로 복사합니다. 군체에 3포인트가 남아 있으면 두 동료가 각각 3포인트를 받습니다. 군체 형태는 해제됩니다. 결속 전 복제한 회수 아이템이나 예전 군체 아이템으로 중복 배치할 수 없습니다.

군체가 쓰러지면 망가진 슬라임 블록이 구성원 기록을 보존합니다. 슬라임볼로 부활하면 대표 개체의 **전체 생명력은 1**이며 두 구성원에게 나눕니다. 동료 둘을 완전한 생명력으로 복구하는 처리가 아닙니다. 부활 후 안전한 곳에서 회수해 해체할 수 있습니다.

## 저장과 복구

결속은 두 구성원과 회수 가능한 군체를 먼저 저장한 뒤 입력을 비웁니다. 해체는 원래 두 동료가 안전하게 돌아올 수 있는지 확인한 뒤 완료합니다. 저장된 진행 기록으로 중단된 처리를 복구하며, 이전 구성원이나 군체 아이템으로 중복 소환할 수 없습니다. 두 과정 모두 먼 청크를 강제로 불러오지 않습니다.

저장 형식과 처리 단계별 검증은 [개발 가이드](DEVELOPMENT.kr.md#집합실과-군체-저장)를 참고하세요.

군체 결속기의 **결과 회수**로 미수령 결과나 복구 가능한 중단 처리를 회수합니다. 결과를 받을 인벤토리 공간을 비워 두세요. 인벤토리가 가득 차도 기록을 지우지 않습니다. JEI는 결속 두 종류와 해체 두 종류를, Patchouli는 한·영 과정을 안내합니다. 두 선택 모드가 없어도 결속기를 사용할 수 있습니다.
