# 안내서 목차

[English](GUIDEBOOK.md) | 한국어 · [게임플레이](GAMEPLAY.kr.md)

**슬라임 동료 안내서**는 Patchouli를 함께 설치하면 사용할 수 있습니다. 책 1개와 슬라임볼 1개를 모양 없이 조합합니다. 일곱 분류에 54개 항목과 171페이지를 한국어·영어로 제공하며, 다른 언어에서는 영어로 표시합니다. 모든 항목은 처음부터 볼 수 있습니다.

슬라임 조작기 항목에는 슬라임 탐색기의 조합법과 사용법도 포함되어 있습니다.

아래 링크에서 해당 내용의 웹 가이드를 볼 수 있습니다. 아이템 도식은 특화 재료를 보여줍니다. 장비와 동료의 저장 특성에는 게임플레이 가이드에서 설명하는 보존 규칙을 적용합니다.
