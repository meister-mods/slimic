# 동료 간 상호작용

[English](INTERACTIONS.md) · [게임플레이](GAMEPLAY.kr.md) · [개발](DEVELOPMENT.kr.md)

동료는 소유권·명령·작업 요청으로 협력합니다. 따라오기와 대기는 작업 요청을 해제합니다. 운반·치유는 원래 주인이 같은 동료나, 서로의 원래 주인을 공동 소유자로 지정한 동료와 협력합니다. 물품 이전은 요청과 실제 공간을 확인합니다. 가디언은 가능한 주인을 보호하고 전투는 공동 소유 관계의 동료를 제외합니다. 한쪽의 공동 소유 지정만으로 상대 플레이어의 보관함을 자동 사용하지는 않습니다.

아래 시나리오는 독립된 GameTest 회귀 검사로 유지합니다. 아이템 이전은 수량뿐 아니라 원본 태그·내구도·장비·현재 생명력의 보존도 확인합니다.

장시간 검증은 서버의 실제 경과 시간을 기록하며 장애물 우회, 운반·치료·수거, 기력 회복과 정확한 아이템 보존을 반복합니다. 각 독립 시나리오는 별도 작업 구역에서 엔티티가 틱을 진행할 수 있는 상태를 확인한 뒤 시작합니다. 저장·복원은 작업 명령, 동료 식별자와 장비 데이터를 확인합니다. 실제 경로 검증과 수종별 지형 검증은 별도 구역을 사용하여 다른 작업 대상이 섞이지 않게 합니다.

0.1.25는 JEI 사용·미사용 환경에서 회귀 검사 424개를 모두 통과했습니다. 29개 시나리오 묶음을 실제 시간으로 두 시간 이상 반복 검증했으며, 별도의 연속 이동 검증에서는 7,212초 동안 288주기를 완료했습니다. 0.1.24 월드를 불러올 때 13종의 저장 특성을 유지하며, JEI를 켠 한국어 환경과 JEI를 끈 영어 환경의 클라이언트 검사도 통과했습니다.

0.1.26은 I30에 해당하는 채굴 협력 검사 14개를 추가합니다. 서로 다른 높이에서 시작한 세 마리가 한 청크를 완전히 굴착한 뒤에도 계단과 정확한 화물 수량을 유지하며, 계단을 만든 슬라임을 회수한 상태에서도 실제 월드 재시작 후 보수한 발판이 남습니다. JEI 유무 모두 전체 438개 검사를 통과합니다. 작업 구역은 엔티티 틱이 가능한 상태까지 준비한 뒤 동료를 소환하며, 동작 검사의 틱 제한은 유지합니다.

0.1.28은 I31–I36과 직업·경계 조건 검사 33개를 추가합니다. Patchouli와 JEI를 각각 켜거나 끈 네 가지 구성에서 전체 기본 서버 회귀 검사 479개를 모두 통과합니다. JEI 사용·미사용 클라이언트에서 직업 장비·테두리 견본·냥냥의 독립 명령을 확인하며, 안내서는 한·영과 영어 대체 표시 및 기본·균일 글꼴을 검증합니다.

0.1.32는 지휘·공동 소유·거점·공유 광원을 다루는 I37–I42를 추가합니다. Patchouli와 JEI를 각각 켜거나 끈 네 구성에서 전체 기본 회귀 검사 516개를 모두 통과합니다. 별도 검사에서는 실제로 언로드된 청크의 스물두 직업을 집합하고, 서버를 완전히 재시작해 고정 목적지와 기존 토큰을 복구하며, 이전 릴리스의 18종과 보관 아이템을 유지합니다. 상호 공동 소유와 해제에 따른 실제 치유·감시·가디언 보호도 확인합니다. 클라이언트 검사는 최소 크기의 한·영 목록과 모든 안내서 페이지를 다룹니다.
