# 왕실 융합

[English](SYNTHESIS.md) | 한국어 · [무너진 성체](FALLEN_SANCTUM.kr.md) · [게임플레이](GAMEPLAY.kr.md)

왕실 융합은 회수한 동료 둘을 소모하여 새 동료 하나를 만듭니다. 0.5.x에서는 **일반 채굴 슬라임 + 고대 채굴 슬라임 → 차세대 채굴 슬라임**, **일반 터널 슬라임 + 고대 터널 슬라임 → 차세대 터널 슬라임**을 지원합니다. 근위 계열의 융합법은 아직 없습니다. 차세대 동료는 다시 융합의 부모로 사용할 수 없습니다.

## 장치와 재료

무너진 성체 심층 중계대에서 **왕실 합성 핵심**을 얻고 다음 유형으로 **왕실 융합 장치**를 제작하세요.

```text
금괴      | 왕실 합성 핵심 | 금괴
레드스톤  | 고대 명령 인장 | 레드스톤
석재 벽돌 | 석재 벽돌      | 석재 벽돌
```

핵심은 제작할 때 소모되며 설치한 장치는 재사용할 수 있습니다. 기존 슬라임 복구 스테이션인 `slimic:command_pedestal`과는 별개입니다. 융합실의 손상된 장치는 작동하지 않으며 무료로 정상 장치를 주지 않습니다. 핵심의 기원 성체는 제작한 장치와 태어난 동료의 계보에 기록됩니다.

융합 한 번에는 **슬라임볼 4개와 오래된 명령 파편 2개**가 필요합니다. 고대 명령 인장은 장치 제작에 쓰이는 별도 아이템이며 파편을 대신하지 않습니다.

## 준비와 확정

1. 지원하는 같은 계열의 살아 있는 일반·고대 슬라임을 하나씩 회수하세요. 유효한 개체 신분이 저장되어 있어야 합니다.
2. 두 부모 모두 **본인이 최초 소유자**여야 합니다. 공동 관리 권한만으로는 융합할 수 없습니다. 월드에 살아 있거나 개체 기록이 충돌하는 부모도 거절됩니다.
3. 장착 칸과 가방을 모두 비우세요. 여분 도구와 보관품도 포함합니다. 거절 사유는 부모와 점유 위치를 표시하며 아이템은 원래 칸에 남습니다. 처음 채굴 아이템으로 특화할 때 저장된 제작 곡괭이도 장비로 취급하므로 소환해 도구를 뺀 뒤 다시 회수하세요. 검증할 수 없는 외부 모드 저장물이 붙어 있으면 소비하지 않고 거절합니다.
4. 장치의 표시된 칸에 부모와 재료를 넣고 포인트 미리보기와 상태를 확인하세요. 미리보기는 아무것도 소모하지 않습니다.
5. 인벤토리 한 칸을 비우고 확정하세요. 서버가 소유권·내용물·개체 신분·재료·성장 이력을 다시 확인한 뒤 두 부모를 정확히 한 번 소모합니다.

결과는 **새 UUID**, 최초 소유자와 동료 기록을 가집니다. **대기** 상태로 태어나며 부모의 이름·장비·화물·투자 스탯을 물려받지 않습니다. 조작기로 이름을 정하세요. 부모의 표시 이름·UUID·계열·융합 게임 시각과 확인된 기원 성체는 계보로 보존됩니다. 고급 툴팁에서 세부 식별 정보를 확인할 수 있습니다.

## 성장 포인트 환원

두 부모가 얻은 것으로 확인되는 **획득 포인트 전체**가 미사용 포인트로 환원됩니다. 이미 투자한 단계와 미사용 잔액을 모두 포함합니다. 최종 능력치·직업 배율·고대 특성·장비 효과는 더하지 않습니다. 고대 복원 시 정식 훈련은 일반 성장 기록으로 확인되면 포함됩니다.

| 개체 | 투자 | 미사용 | 획득 합계 |
| --- | ---: | ---: | ---: |
| 일반 채굴 부모 | 21 | 4 | 25 |
| 고대 채굴 부모 | 16 | 2 | 18 |
| 새 동료 | 0 | **43** | **43** |

다음 포인트 비용은 계승한 성장을 포함해 `min(4096, 32 + 획득 포인트 × 64)` 활동량으로 계산합니다. 43포인트를 계승하면 2,784가 필요합니다. 일반 능력치별 훈련 상한은 그대로입니다. 상한을 채워도 남는 포인트는 보관하며 환원량을 몰래 줄이지 않습니다.

잔액은 음수가 아닌 부호 있는 64비트 정수로 저장하고 메뉴에도 정확히 동기화합니다. 표현할 수 없는 합계는 두 원본을 보존한 채 거절합니다. 크리에이티브 편집값은 계승 성장으로 바뀌지 않습니다. 0.3.x 동료는 투자·미사용 합계와 저장된 획득 이력이 일치하면 사용할 수 있으며, 확인할 수 없는 이력은 명시적으로 거절하고 원본을 유지합니다.

## 채굴 정책

새 동료의 **슬라임 조작기 관리 화면 → 채굴 정책**을 여세요. 기본값은 일반이며 정책 변경만으로 채굴 명령을 내리지는 않습니다.

| 정책 | 동작 |
| --- | --- |
| 일반 | 기존 배수·외벽·도구·공유 계단 규칙에 따라 현재 청크 굴착 |
| 광석 우선 | 현재 작업층에서 보이는 Forge 광석을 우선; 먼 광맥을 드러내거나 층을 건너뛰지 않음 |
| 정밀 탐광 | 2×2 수직굴과 가지굴로 벽 너머 선택 광맥에 접근하며 위험 지형 우회 |

선택 광석을 대신하는 **정밀 탐광**은 현재 위치에서 **가로·세로 두 칸의 수직굴**을 한 층씩 파 내려갑니다. 몸체의 너비와 높이는 일반 채굴 슬라임의 75%인 약 **0.78블록**이며 가지굴은 **폭 2칸·높이 2칸**입니다. 작업 명령은 조작기에서 따로 내려야 합니다.

주변의 로드된 지형에서 활성 Forge 광석 태그를 벽 너머로 탐지하고, 선택한 광맥으로 이어지는 바닥이 받쳐 주는 가지굴을 계획합니다. 높이가 다르면 두 칸 전진하며 한 층 오르내리는 경사 통로를 시도합니다. 파괴는 도구가 닿고 보이는 앞쪽 블록부터 수행하며, 드러난 선택 광석을 우선 회수합니다. 접근로를 만드는 데 필요한 돌·흙·선택하지 않은 광석도 가방에 담습니다. 광석의 드롭량이나 도구 등급을 바꾸지는 않습니다. 대상 태그는 석탄·구리·철·금·레드스톤·청금석·다이아몬드·에메랄드·석영·고대 잔해입니다.

새 통로의 바닥 네 칸, 단면, 인접 유체와 낙하 블록 천장을 확인합니다. 마그마 블록을 피하고 모래·자갈 바닥은 아래의 단단한 지지까지 확인합니다. 바닥이 없는 공동이나 물·용암을 만나는 경로는 피하고, 수직굴을 계속할 수 있는 다른 지점으로 옆굴을 파는 우회를 시도합니다. 안전한 길이 없으면 접근 불가로 멈춥니다. 유체를 강제로 제거하거나 위험한 구멍으로 뛰어들지는 않습니다. 기존 채굴 계단·블록 엔티티·파괴 불가능한 블록·보호 이벤트는 유지합니다. 경로는 매 단계 다시 검사하고, 광맥 작업 후에는 지나온 가지굴로 수직굴 전면에 돌아옵니다.

정밀 탐광은 새 청크를 불러오지 않습니다. 기본 강화 범위는 그대로 적용하며, 매우 큰 크리에이티브 탐지값도 한 번의 탐색 창은 반경 32블록으로 제한합니다. 출입용 사다리나 지상 복귀 계단을 자동으로 만들지는 않으므로, 깊은 작업에 운반 동료가 왕복하려면 별도의 연결 통로를 준비하세요. 선택 태그 변경은 새 대상을 다시 탐색하며 수직굴 진행은 유지합니다.

슬라임 탐색기는 **2×2 수직굴**, 탐지 창, 현재 계획된 다음 단면을 표시합니다. 미리보기만으로 지형을 조사하거나 숨은 광석 위치를 표시하지 않습니다.

선택 광석이 없는 청크 섹션은 블록 팔레트로 빠르게 건너뛰고, 해당 광석을 포함한 로드된 섹션은 나누어 검사합니다. 일시적인 이동 실패에는 다음 굴착 위치를 보존해 재시도하므로, 이전 바닥을 이미 팠더라도 재개할 수 있습니다. 기력이 고갈되면 회복할 때까지 쉽니다. 이전 저장에서도 인접한 다음 층이 이미 파여 있고 안전하면 기존 작업 명령을 재개할 수 있습니다.

체력·최대 기력·적재량은 일반 채굴 슬라임 기준이며 **고대 채굴의 기력 지출 절반 특성을 모든 정책에서 계승**합니다. 운반·창고 동료는 접근 가능한 곳에서 도구 보급과 화물 수거를 돕고 파발 동료는 중단 사유를 안내합니다. 회수·부활·포탈·재배치는 기존 보존 규칙을 따르며 대기로 돌아옵니다. 이전 버전에서 선택 광석으로 저장된 개체는 정책과 특성을 유지하되 대기 상태로 전환되므로 새 굴착을 시작하려면 작업을 명시적으로 재개하세요.

## 터널 단면 설정

**차세대 터널 슬라임**은 일반 터널 슬라임과 고대 터널 슬라임을 융합해 얻습니다. 채굴 계열과 같은 슬라임볼 4개·오래된 명령 파편 2개를 사용하며, 부모 검증·성장 환원·거래 복구 규칙도 같습니다. 부모의 장비와 가방을 모두 비워야 합니다. 부모 둘을 소모하고 새 신분의 동료가 **대기**, 기본 **3×3** 단면으로 태어납니다.

**슬라임 조작기 → 터널 단면**에서 양의 정수 **n**을 입력하고 적용하면 **폭 n칸·높이 n칸**의 정사각형 터널을 팝니다. 1×1·2×2·5×5와 더 큰 단면을 같은 방식으로 지정합니다. 크기나 방향을 바꾸면 대기하며 터널 명령은 따로 내려야 합니다. 설정 가능한 최댓값은 차원의 건축 높이에서 바닥·천장 여백을 뺀 값입니다. 현재 작업 높이에서 단면과 테두리 전체가 건축 높이나 월드 경계를 벗어나면 해당 단면을 변경하기 전에 멈춥니다. 크기 선택에는 강화 포인트가 들지 않습니다.

0.78블록의 작은 몸체와 좁은 수레로 1×1 굴을 통과합니다. 입구에서 정면 단면의 작업 범위를 확장해 블록마다 원래 파괴 시간·도구 내구도를 적용하며, 바닥·천장·양옆 보강을 마친 뒤 실제로 전진합니다. 홀수·짝수 폭 모두 기존 진행 중심선을 사용합니다. 단면이 커지면 굴착량과 자재 수요도 늘어납니다. 틱마다 최대 128칸을 확인하고 완료한 블록 행동은 한 번만 수행하며, 로드되지 않은 청크는 불러오지 않습니다. 테두리 좌표는 필요한 칸만 계산합니다. 최종 확인 뒤 새 블록이 전진을 막으면 단면을 다시 확인하고 굴착을 재개합니다.

테두리 견본은 소모하지 않으며 실제 건축 블록·도구·빈 양동이는 가방에서 사용합니다. 운반·창고 동료의 보급과 화물 수거, 파발 동료의 중단 안내를 지원합니다. 도구 등급·블록 엔티티·공유 채굴 계단·Forge 보호·`mobGriefing`을 지킵니다. 기력 소모량 절반과 고대 석재 작업 속도 1.5배 특성을 계승합니다. 크기·방향·견본·작업 단면의 진행과 배수한 칸은 저장하며 회수 후에는 대기로 배치됩니다.

## 중단된 거래

입력을 소모하기 전에 저장 세계 공용 거래 기록에 부모 UUID, 입력 전후 상태, 결과 신분, 수령자와 지급 식별자를 저장합니다. 오래된 장치 저장본은 확정된 기록과 대조합니다. 반복 확정·다른 장치·부모 아이템 복제로 소모된 부모를 다시 사용할 수 없습니다. 외부 모드는 확정 전 이벤트를 취소할 수 있습니다.

확정된 결과는 원래 장치를 부숴도 수령자에게 남습니다. 작동하는 왕실 융합 장치의 **미수령 결과 회수**를 사용하세요. 새 결과는 플레이어 저장이 성공할 때까지 보관됩니다. 이미 인벤토리에 지급 식별자가 있으면 복제하지 않고 해당 아이템의 저장을 다시 확인합니다. 공간을 확보하고 저장 문제를 해결한 뒤 재시도하세요.

JEI를 설치하면 전용 장치 융합 분류를 제공합니다. Patchouli 안내서는 장치 조합법·준비·성장 계승·정책·성체 탐험 경로를 영·한으로 안내합니다. 두 선택 모드 없이도 융합할 수 있습니다.
