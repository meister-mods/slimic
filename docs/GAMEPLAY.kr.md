# 게임플레이 가이드

[English](GAMEPLAY.md) | 한국어 · [프로젝트 개요](../README.kr.md)

공용 스탯을 강화해 성장하는 슬라임 동료와 채굴·운반 특화 슬라임을 제공합니다.

## 설치

Minecraft 1.20.1, Forge 47.x(47.4.10 기준 개발), Java 17을 사용합니다. 빌드 또는 배포 파일의 `slimic-1.20.1-*.jar`를 Minecraft의 `mods` 폴더에 넣고 Forge 프로필로 실행합니다. `-sources.jar`는 개발용이므로 설치하지 않습니다.

## 친근한 슬라임 제작

제작대 가운데에 소울 샌드 또는 소울 소일 1개를 놓고 슬라임볼 8개로 둘러싸면 **친근한 슬라임(Friendly Slime)** 아이템 1개를 만듭니다.

| 슬라임볼 | 슬라임볼 | 슬라임볼 |
| --- | --- | --- |
| 슬라임볼 | 소울 샌드 / 소울 소일 | 슬라임볼 |
| 슬라임볼 | 슬라임볼 | 슬라임볼 |

크리에이티브의 Slimic 탭에서도 아이템을 찾을 수 있습니다.

## 소환과 조작

스폰 알처럼 블록이나 물 근원에 아이템을 사용합니다. 새로 제작한 아이템은 사용자에게 길들여진 슬라임을 소환합니다. 서바이벌에서는 소환 성공 시 아이템 1개를 소모하며, 새로 제작한 아이템은 크리에이티브에서 반복 사용할 수 있습니다.

모루에서 아이템에 붙인 이름은 슬라임의 사용자 지정 이름이 됩니다.

| 조작 | 동작 |
| --- | --- |
| 주인이 우클릭 | 스탯·강화·이름·장비·가방·행동을 관리하는 화면을 엽니다. |
| 주인이 Shift+우클릭 | 다른 아이템을 들고 있어도 인벤토리로 회수합니다. |
| 회수한 아이템을 블록이나 물 근원에 사용 | 저장된 특성을 유지한 채 같은 슬라임을 다시 소환합니다. |

회수와 따라오기·대기 지시는 주인만 할 수 있습니다. 다른 플레이어가 회수 아이템을 사용해도 원래 주인은 바뀌지 않습니다.

## 회수와 특성 유지

회수 시 슬라임의 영구 저장 상태 전체를 보관합니다. 현재 생명력이 그대로 유지되며, 다시 소환한다고 회복되지 않습니다. 다음과 같은 특성을 보존합니다.

- 최대 생명력과 다른 능력치, 영구 능력치 보정값
- 적용 중인 효과와 남은 지속시간
- 사용자 지정 이름, 소유권, 따라오기·대기 지시
- 개체의 식별 정보, 나이, 장비와 다른 저장 속성
- 앞으로 추가될 슬라임 특성에 사용하는 영구 사용자 데이터

회수한 슬라임 아이템은 겹쳐지지 않고 각각 별도 칸을 사용합니다. 인벤토리·상자·월드를 저장하고 불러와도 상태를 유지합니다. 아이템으로 보관하는 동안에는 효과 지속시간 등 저장된 타이머가 진행되지 않습니다.

회수하려면 주 인벤토리에 빈 칸이 하나 있어야 합니다. 가득 차 있으면 회수를 취소하고 슬라임과 상태를 그대로 남깁니다. 이미 죽었거나 죽는 중인 슬라임은 회수할 수 없습니다.

회수한 아이템은 서바이벌과 크리에이티브 모두 재소환에 성공하면 소모합니다. 블록에 막혀 소환할 수 없는 경우에는 아이템과 저장 상태를 유지합니다.

슬라임은 새로 지정한 위치에 나타납니다. 기존 이동 속도와 낙하 거리는 초기화해 이전의 낙하가 새 위치로 이어지지 않게 합니다. 회수 시 끈은 반환하고 탑승 관계는 해제합니다.

## 동료의 행동

슬라임은 점프하며 주인을 따라다닙니다. 소유권과 대기 지시는 저장 후 다시 불러와도 유지됩니다. 평화로움에서도 사라지지 않고 공격하거나 죽을 때 분열하지 않습니다.

슬라임에는 Minecraft 원본 슬라임 텍스처에 염색 필터를 적용하며, 소환 아이콘에는 슬라임볼 형태와 전문화별 색·상징을 사용합니다. 출처는 [CREDITS.txt](../CREDITS.txt)에 정리되어 있습니다.

## 공용 스탯과 성장

자신의 슬라임을 우클릭해 관리 화면을 엽니다. 이름 입력란에서 설정한 이름은 이름표처럼 슬라임 위에 표시됩니다. 따라오기와 대기 버튼으로 행동을 바꿉니다. 채굴 슬라임에는 채굴 버튼·곡괭이·삽 장비 칸·가방이 있으며, 운반 슬라임에는 운반 버튼과 더 큰 가방이 있고 장착 칸은 없습니다.

| 스탯 | 기본값 | 포인트당 증가 | 역할 |
| --- | --- | --- | --- |
| 체력 | 16 | +4 | 최대 생명력입니다. 강화해도 현재 생명력을 회복하지 않습니다. |
| 공격력 | 2 | +1 | 공격 시 기본 피해량입니다. 채굴 동료는 자동 전투를 하지 않습니다. |
| 방어력 | 0 | +1 | Minecraft 기본 갑옷 속성과 피해 감소 공식을 사용합니다. |
| 이동속도 | 0.30 | +0.015 | Minecraft 이동속도 속성입니다. |
| 작업속도 | 1.0배 | +0.1배 | 채굴 진행 속도와 운반 동작 주기에 적용합니다. |
| 운반력 | 9칸 / 운반 슬라임 18칸 | +3칸 / 운반 슬라임 +6칸 | 가방의 사용 가능한 칸으로, 최대 27칸 또는 운반 슬라임 54칸입니다. |
| 지구력 | 100 | +20 | 연속 작업에 사용하는 최대 에너지입니다. |
| 사거리 | 3블록 | +0.25블록 | 채굴과 아이템 전달을 실행할 수 있는 최대 거리입니다. |
| 탐지 범위 | 8블록 | +1블록 | 채굴 대상을 찾는 반경과 운반 작업 구역의 반경입니다. |

운반력은 6단계, 나머지 스탯은 20단계까지 강화합니다. 포인트 사용·이름 변경·관리 인벤토리는 주인만 조작할 수 있습니다. 스탯, 미사용 포인트, 활동 진행도와 현재 지구력은 월드 저장과 회수 후에도 유지됩니다.

첫 스탯 포인트는 작업 진행도 256을 쌓으면 획득합니다. 포인트를 얻을 때마다 다음 요구량이 64씩 늘어나며 최대 4,096입니다. 채굴은 블록 1개 채굴에 성공할 때마다 진행도 1을 얻습니다. 운반은 슬라임 상자에 화물 묶음을 옮기거나 동료에게 교체 도구를 전달할 때마다 1을 얻으며, 화물 수거나 도구를 가져오는 단계에는 진행도를 얻지 않습니다. 가만히 있기, 따라오기, 지시 변경과 회수·소환, 실패한 동작은 진행도를 얻지 않습니다.

## 채굴 슬라임

친근한 슬라임 소환 아이템과 아무 곡괭이를 정해진 모양 없이 조합하면 **채굴 슬라임**이 됩니다. 저장된 동료 특성과 조합에 사용한 곡괭이의 종류, 내구도, 이름, 마법 부여를 보존하며, 소환 시 해당 곡괭이를 장착합니다. 크리에이티브 탭의 기본 아이템은 장비 두 칸이 비어 있습니다.

관리 화면에는 곡괭이와 삽을 위한 별도 장비 칸과 가방이 있습니다. 노란 채굴 모자를 쓰며 현재 사용하는 도구를 손에 든 방향으로 표시합니다. 삽에 적합한 지형에는 삽을 우선 사용하고, 블록의 도구 등급 조건을 충족하면 다른 도구도 사용합니다. 실제 도구에 따라 채굴 속도, 드롭, 행운, 섬세한 손길, 내구성 및 내구도 소모가 적용됩니다. 장비가 비거나 도구가 부러지면 가방의 호환되는 예비 도구를 자동으로 꺼내 장착합니다. 적절한 도구나 등급이 없으면 작업을 멈춥니다.

처음 소환하면 배치된 청크에서 작업을 시작합니다. 배치 높이를 기준으로 수평 층을 하나씩 내려가며 흙, 돌, 광석 등 지형 전체를 굴착합니다. 회수 후 **같은 청크**에 놓으면 기존 층과 명령을 유지합니다. **다른 청크**에 놓으면 새 높이를 기준으로 굴착 구역을 만들고 자동으로 작업을 시작합니다. 생명력, 스탯, 도구, 가방 등은 유지됩니다.

청크 가장자리를 따라 폭 2칸의 계단과 평평한 모서리 발판을 남깁니다. 기존의 단단한 바닥은 보존하고, 빠진 발판은 가방의 조약돌, 흙, 돌, 심층암 등 일반적인 완전한 블록으로 보강합니다. 설치마다 재료 한 개를 소비합니다. 재료가 없거나 설치가 막히면 멈추므로 가방에 건축 블록을 공급하세요.

청크 밖을 채굴하거나 이웃 청크를 불러오지 않습니다. 공기, 액체, 블록 엔티티, 파괴 불가능한 블록은 건너뜁니다. 한 층 전체가 파괴 불가능한 바닥이거나 차원의 최저 높이에 도달하면 작업이 완료됩니다. 보호된 상자, 액체, 장애물이 통행을 막으면 직접 정리해야 할 수 있습니다. 파괴와 발판 설치는 Forge 이벤트와 `mobGriefing` 설정을 따릅니다. 대상에 접근한 뒤 탐지 범위 안에서 도달 거리를 만족할 때 작업합니다.

드롭은 가방에 직접 들어갑니다. 드롭 전체를 담을 수 없으면 블록과 도구 내구도를 유지한 채 대기하며, 가방을 비우거나 적재량을 높이면 재개합니다. 블록 하나마다 기력 1을 사용하며, 고갈되면 초당 2씩 회복해 최대 기력의 25%에 도달한 후 재개합니다. 작업하지 않는 동안에도 회복합니다.

## 슬라임 상자

슬라임볼 주위에 나무 판자 8개를 배치하면 **슬라임 상자**를 만듭니다. 판자 종류를 섞어도 조합할 수 있습니다. 우클릭하면 27칸 인벤토리를 열며 자원과 여분 도구를 보관할 수 있습니다. 월드를 저장해도 내용물을 유지하고 일반적인 아이템 자동화와 비교기 출력을 지원합니다. 부수면 상자와 내용물을 각각 떨어뜨립니다.

슬라임 상자는 주변 운반 슬라임이 공유하는 물류 보관함입니다. 일반 상자는 운반 슬라임 제작 재료로만 사용하며 자동 수거·적재 대상으로 취급하지 않습니다. 잠긴 슬라임 상자는 이용하지 않습니다.

## 운반 슬라임

친근한 슬라임 소환 아이템과 **일반 상자**를 정해진 모양 없이 조합하면 **운반 슬라임**을 만듭니다. 특화할 때 저장된 동료의 특성을 유지합니다. 운반 슬라임에는 장착 칸이 없으며 도구도 일반 가방에 넣어 운반합니다.

운반력은 같은 강화 단계의 다른 슬라임보다 항상 정확히 2배입니다. 기본 18칸에서 강화마다 6칸이 늘어나 최대 54칸이 됩니다. 관리 화면의 화살표 버튼으로 가방 두 페이지를 전환합니다. Shift+클릭으로 현재 페이지의 가방과 플레이어 인벤토리 사이에서 화물을 옮깁니다.

새로 제작한 운반 슬라임은 소환 즉시 운반을 시작합니다. 소환 위치를 중심으로 탐지 범위만큼의 작업 구역을 가지며, 그 안에 로드된 슬라임 상자와 같은 주인의 작업 동료를 찾습니다. 직접 이동하고 사거리와 시야 안에서 아이템을 전달합니다. 이동해도 작업 구역 중심은 유지되며, 회수 후 다시 소환하면 중심을 새 위치로 정합니다. 작업 대상을 찾으려고 주변 청크를 강제로 불러오지 않습니다.

동료가 가방 포화로 멈추면 다가가 자신의 가방에 담을 수 있는 만큼 수거한 뒤 여유가 있는 슬라임 상자로 옮깁니다. 동료는 공간이 생기면 작업을 재개합니다. 부분적으로 찬 묶음에 합치고 필요하면 다른 상자도 이용합니다. 이용 가능한 상자에 공간이 없으면 화물을 운반 가방에 보관하며 버리지 않습니다. 공간이 생기면 다시 전달합니다.

동료가 도구 고장이나 부재로 멈추면 슬라임 상자에서 호환되는 여분 도구 1개를 가져와 보급합니다. 채굴 슬라임에는 필요한 곡괭이나 삽을 보급하며, 소모된 내구도·마법 부여·이름을 유지합니다. 다른 운반 슬라임이 먼저 보급했다면 남은 도구는 가방에 보관해 다른 동료에게 쓰거나 상자로 돌려보냅니다. 대기·따라오기 지시를 받은 동료에게는 임의로 도구를 보급하지 않습니다.

화물 묶음의 수거·적재와 도구의 수거·보급마다 지구력 1을 소모합니다. 바닥나면 초당 2씩 회복해 최대치의 25%가 될 때까지 쉽니다. 작업속도가 높으면 전달 동작 사이의 대기 시간이 줄어듭니다. 따라오기·대기 지시는 물류 작업을 중단하며, 가방 전체 내용물·스탯·현재 지구력·성장 진행도·지시는 월드 저장과 회수 후에도 유지됩니다.

## JEI

JEI는 선택 사항입니다. 설치하면 친근한 슬라임·슬라임 상자 조합법, 등록된 곡괭이별 채굴 슬라임 조합법, 운반·파발 슬라임 조합법과 동료 안내를 표시합니다. 채굴 슬라임 미리보기에는 해당 장착 도구가 반영됩니다. JEI 없이도 Slimic을 사용할 수 있습니다.

## 염색

소유한 슬라임에 염료를 들고 우클릭하면 기존 슬라임 텍스처에 해당 색 필터를 적용합니다. 친근한 슬라임, 채굴, 운반, 파발 슬라임 모두 지원하며 장비 색은 유지됩니다. 서바이벌에서는 염료 한 개를 소비하고 크리에이티브에서는 소비하지 않습니다. 색은 저장, 전문화, 회수, 재배치 후에도 유지됩니다. Shift 우클릭은 회수 동작입니다.

## 파발 슬라임

친근한 슬라임 소환 아이템과 아무 폭죽 로켓을 정해진 모양 없이 조합하면 **파발 슬라임**이 됩니다. 조합한 폭죽의 모양, 색, 색 변화, 잔상, 반짝임, 비행 시간을 그대로 보존합니다. 조합 재료만 소비하며 이후 신호를 보낼 때 추가 폭죽을 요구하지 않습니다. 크리에이티브 기본 아이템은 하얀색의 작은 원형 폭죽을 사용합니다.

탐지 범위 안에서 같은 소유자의 작업 슬라임을 살핍니다. 설정한 시간 이상 계속 작업 불능 상태라면 폭죽을 발사합니다. 신호 폭죽은 생명체에 피해를 주지 않습니다. 도구 부족, 도구 등급 부족, 가방 포화, 기력 고갈, 작업 비활성화, 접근 불가, 운송 경로 부족 등이 작업을 막을 수 있습니다. 수동 대기·따라오기 명령과 완료된 굴착은 작업 불능으로 세지 않습니다.

관리 화면에서 감시·따라오기·대기 명령과 1~60분의 지연 시간을 설정합니다. 기본값은 5분이며 월드의 `serverconfig/slimic-server.toml`에 있는 `heraldDelayMinutes`로 조정합니다. 같은 작업 불능 상태에는 한 번만 신호를 보내며 신호 사이에는 짧은 재사용 대기시간이 있습니다. 유효한 작업을 재개한 뒤 다시 막히면 새 신호를 보낼 수 있습니다. 폭죽 디자인, 지연 시간, 명령, 경고 기록, 작업 불능 타이머는 회수 후에도 유지되며 아이템 상태에서는 시간이 흐르지 않습니다.

## 슬라임 튜너

**슬라임 튜너**는 Slimic 크리에이티브 탭에 있는 전용 도구로 서바이벌 조합법은 없습니다. 들고 우클릭하면 16블록 안에서 조준한 슬라임의 별도 스탯 편집 화면이 열립니다. 조준 대상이 없으면 범위 안의 가장 가까운 슬라임을 선택합니다. 슬라임을 직접 우클릭해도 열 수 있습니다. 사용하는 동안 크리에이티브 모드이며 튜너를 들고 있어야 합니다.

기본 스탯, 현재 생명력, 현재 기력, 미사용 포인트를 수정합니다. 영구 속성 보정은 별도로 계속 적용됩니다. 운반 슬라임의 적재량은 입력한 공통 기본값의 두 배입니다. 적용 버튼은 유효한 변경을 함께 저장하며 새로고침은 현재 값을 다시 읽습니다. 적재량을 줄일 때는 제외될 가방 칸을 먼저 비워야 합니다. 최대 생명력을 바꾸어도 현재 생명력이 자동으로 채워지지는 않습니다.

| 항목 | 범위 |
| --- | --- |
| 생명력 | 1~1,024 |
| 공격력 | 0~2,048 |
| 방어력 | 0~30 |
| 이동 속도 | 0~10 |
| 작업 속도 | 0.1~32 |
| 적재량 | 정수 1~27칸, 운반은 2~54칸 |
| 기력 | 1~2,000 |
| 도달 거리 | 0~32 |
| 탐지 범위 | 0~64 |
| 현재 생명력·기력 | 0부터 적용 후 최댓값까지 |
| 미사용 포인트 | 정수 0~32,767 |

조정값과 현재 상태는 회수·재배치 후에도 유지됩니다. 일반 스탯 강화도 각 단계 한도 안에서 사용할 수 있습니다.
