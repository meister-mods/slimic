# 동료 간 상호작용

[English](INTERACTIONS.md) · [게임플레이](GAMEPLAY.kr.md) · [개발](DEVELOPMENT.kr.md)

동료는 소유권·명령·작업 요청으로 협력합니다. 따라오기와 대기는 작업 요청을 해제합니다. 운반은 같은 소유자의 요청과 실제 가방 여유를 확인하며, 치유는 같은 소유자의 유효한 환자만 치료합니다. 가디언 엔젤은 가까운 주인을 보호하고 전투 슬라임은 같은 소유자의 동료를 공격하지 않습니다.

아래 시나리오는 독립된 GameTest 회귀 검사로 유지합니다. 아이템 이전은 수량뿐 아니라 원본 태그·내구도·장비·현재 생명력의 보존도 확인합니다.

| 번호 | 참여 동료 | 기대 동작 |
| --- | --- | --- |
| I01 | 운반 / 채굴 | 가득 찬 채굴 가방을 비우고 채굴을 재개합니다. |
| I02 | 운반 / 채굴 | 손상·이름·마법 부여를 유지한 원본 예비 도구를 보급합니다. |
| I03 | 운반 / 채굴 | 양동이 한 개를 보급하고 유체 제거를 재개합니다. |
| I04 | 운반 / 채굴 | 벽 보강 조약돌은 요청한 한 묶음 이내로 보급합니다. |
| I05 | 운반 / 농사 / 벌목 | 작업자에 맞는 괭이·도끼를 구분합니다. |
| I06 | 운반 / 전투 | 없는 검을 보급하며 다른 장비를 유지합니다. |
| I07 | 운반 / 청소 | 청소 가방을 비우고 수거를 재개합니다. |
| I08 | 운반 / 치유 / 창고 | 같은 소유자의 대기 중인 창고에서도 치유 재료를 보급합니다. |
| I09 | 창고 / 작업자 | 슬라임 상자가 없어도 요청한 화물을 수거합니다. |
| I10 | 운반 / 창고 | 더 가까운 상자보다 유효한 소유 창고를 우선합니다. |
| I11 | 운반 / 창고 | 창고가 가득 차면 상자를 사용합니다. |
| I12 | 운반 / 창고 | 창고에 일부를 넣은 뒤 남은 화물을 옮깁니다. |
| I13 | 운반 / 창고 | 다른 소유자의 창고를 사용하지 않습니다. |
| I14 | 운반 / 창고 | 이전 직전에 바뀐 소유권을 반영합니다. |
| I15 | 치유 / 환자 | 실제로 치료를 완료한 치유 슬라임만 비용을 소비합니다. |
| I16 | 치유 / 파발 | 접근 실패를 반복해도 중단 시간을 유지해 파발이 알립니다. |
| I17 | 치유 / 저장 동료 | 같은 개체의 중복 부활은 비용 없이 거부합니다. |
| I18 | 치유 / 창고 | 변경한 적재량과 마지막 칸 화물을 유지해 부활합니다. |
| I19 | 작업자 / 운반 / 창고 | 여러 동료가 경쟁해도 화물 수량과 출처 태그를 유지합니다. |
| I20 | 운반 / 치유 | 동시 보급도 요청 상한을 넘지 않습니다. |
| I21 | 가디언 엔젤 / 주인 | 주인이 든 토템이 우선하며 같은 구조에는 보관 토템 하나만 소비합니다. |
| I22 | 치유 / 안장 | 갑옷·날개·안장·대기 명령을 유지하며 치료합니다. |
| I23 | 치유 / 안장 | 세 장비의 원본 데이터를 유지하고 생명력 1로 부활합니다. |
| I24 | 가디언 엔젤 / 안장 / 주인 | 탑승 관계와 장비를 유지하며 주인을 보호합니다. |
| I25 | 전투 / 13종 슬라임 | 모든 전투 분류를 켜도 같은 소유자의 동료는 제외합니다. |
| I26 | 운반 / 작업자 | 여러 운반 슬라임이 예비 도구를 복제하지 않습니다. |
| I27 | 파발 / 작업자 | 발사 콜백이 감시를 취소하면 나머지 알림도 멈춥니다. |
| I28 | 창고 / 작업자 | 로드된 실제 우회 경로로 화물에 접근합니다. |
| I29 | 치유 / 눅눅 | 치료 중 자유 이동 명령과 고정 중심을 유지합니다. |

장시간 검증은 서버의 실제 경과 시간을 기준으로 최소 두 시간 동안 진행합니다. 장애물 우회, 운반·치료·수거, 기력 회복과 정확한 아이템 보존을 반복합니다. 각 독립 시나리오는 별도 작업 구역에서 엔티티가 틱을 진행할 수 있는 상태를 확인한 뒤 시작합니다. 저장·복원은 작업 명령, 동료 식별자와 장비 데이터를 확인합니다. 실제 경로 검증과 수종별 지형 검증은 별도 구역을 사용하여 다른 작업 대상이 섞이지 않게 합니다.

0.1.25는 JEI 사용·미사용 환경에서 회귀 검사 424개를 모두 통과했습니다. 29개 시나리오 묶음을 실제 시간으로 두 시간 이상 반복 검증했으며, 별도의 연속 이동 검증에서는 7,212초 동안 288주기를 완료했습니다. 0.1.24 월드를 불러올 때 13종의 저장 특성을 유지하며, JEI를 켠 한국어 환경과 JEI를 끈 영어 환경의 클라이언트 검사도 통과했습니다.
