# Slimic

[English](README.md) | 한국어

> 슬라임을 육성하고 업무를 맡겨 조수로 활용하세요.

Slimic은 친근한 슬라임을 육성하고 업무를 지시해 조수로 활용하는 Minecraft Forge 모드입니다.

## 개요

슬라임은 공용 스탯과 활동 기반 강화를 통해 성장합니다. 이름과 행동을 관리하고, 특성을 보존한 채 아이템으로 회수할 수 있습니다. 채굴 슬라임은 지형을 굴착하고, 운반 슬라임은 화물과 도구를 옮기며, 파발 슬라임은 작업 중단을 알립니다. 전투 슬라임은 지정한 적과 싸우고, 청소 슬라임은 바닥의 아이템을 수거하며, 농사 슬라임은 작물을 기르고, 벌목 슬라임은 나무를 관리하며, 안장 슬라임은 지상과 하늘에서 주인을 태우고 이동합니다. 염색으로 동료를 구분하고 크리에이티브 전용 튜너로 스탯을 조정할 수 있습니다. JEI에서 조합법을 확인할 수 있습니다.

프로젝트는 `0.1.x` 범위의 초기 개발 단계입니다.

## 지원 환경

Minecraft **1.20.1**, Minecraft Forge **47.x**, Java **17**을 사용합니다.
