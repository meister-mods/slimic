# 게임플레이 가이드

[English](GAMEPLAY.md) | 한국어 · [프로젝트 개요](../README.kr.md)

공용 스탯을 강화해 성장하는 슬라임 동료와 채굴 특화 슬라임을 제공합니다.

## 설치

Minecraft 1.20.1, Forge 47.x(47.4.10 기준 개발), Java 17을 사용합니다. 빌드 또는 배포 파일의 `slimic-1.20.1-*.jar`를 Minecraft의 `mods` 폴더에 넣고 Forge 프로필로 실행합니다. `-sources.jar`는 개발용이므로 설치하지 않습니다.

## 친근한 슬라임 제작

제작대 가운데에 소울 샌드 또는 소울 소일 1개를 놓고 슬라임 블록 8개로 둘러싸면 **친근한 슬라임(Friendly Slime)** 아이템 1개를 만듭니다.

| 슬라임 블록 | 슬라임 블록 | 슬라임 블록 |
| --- | --- | --- |
| 슬라임 블록 | 소울 샌드 / 소울 소일 | 슬라임 블록 |
| 슬라임 블록 | 슬라임 블록 | 슬라임 블록 |

크리에이티브의 스폰 알 탭에서도 아이템을 찾을 수 있습니다.

## 소환과 조작

스폰 알처럼 블록이나 물 근원에 아이템을 사용합니다. 새로 제작한 아이템은 사용자에게 길들여진 슬라임을 소환합니다. 서바이벌에서는 소환 성공 시 아이템 1개를 소모하며, 새로 제작한 아이템은 크리에이티브에서 반복 사용할 수 있습니다.

모루에서 아이템에 붙인 이름은 슬라임의 사용자 지정 이름이 됩니다.

| 조작 | 동작 |
| --- | --- |
| 주인이 우클릭 | 스탯·강화·이름·장비·가방·행동을 관리하는 화면을 엽니다. |
| 주인이 Shift+우클릭 | 다른 아이템을 들고 있어도 인벤토리로 회수합니다. |
| 회수한 아이템을 블록이나 물 근원에 사용 | 저장된 특성을 유지한 채 같은 슬라임을 다시 소환합니다. |

회수와 따라오기·대기 지시는 주인만 할 수 있습니다. 다른 플레이어가 회수 아이템을 사용해도 원래 주인은 바뀌지 않습니다.

## 회수와 특성 유지

회수 시 슬라임의 영구 저장 상태 전체를 보관합니다. 현재 생명력이 그대로 유지되며, 다시 소환한다고 회복되지 않습니다. 다음과 같은 특성을 보존합니다.

- 최대 생명력과 다른 능력치, 영구 능력치 보정값
- 적용 중인 효과와 남은 지속시간
- 사용자 지정 이름, 소유권, 따라오기·대기 지시
- 개체의 식별 정보, 나이, 장비와 다른 저장 속성
- 앞으로 추가될 슬라임 특성에 사용하는 영구 사용자 데이터

회수한 슬라임 아이템은 겹쳐지지 않고 각각 별도 칸을 사용합니다. 인벤토리·상자·월드를 저장하고 불러와도 상태를 유지합니다. 아이템으로 보관하는 동안에는 효과 지속시간 등 저장된 타이머가 진행되지 않습니다.

회수하려면 주 인벤토리에 빈 칸이 하나 있어야 합니다. 가득 차 있으면 회수를 취소하고 슬라임과 상태를 그대로 남깁니다. 이미 죽었거나 죽는 중인 슬라임은 회수할 수 없습니다.

회수한 아이템은 서바이벌과 크리에이티브 모두 재소환에 성공하면 소모합니다. 블록에 막혀 소환할 수 없는 경우에는 아이템과 저장 상태를 유지합니다.

슬라임은 새로 지정한 위치에 나타납니다. 기존 이동 속도와 낙하 거리는 초기화해 이전의 낙하가 새 위치로 이어지지 않게 합니다. 회수 시 끈은 반환하고 탑승 관계는 해제합니다.

## 동료의 행동

슬라임은 점프하며 주인을 따라다닙니다. 소유권과 대기 지시는 저장 후 다시 불러와도 유지됩니다. 평화로움에서도 사라지지 않고 공격하거나 죽을 때 분열하지 않습니다.

슬라임 텍스처와 아이템 아이콘에는 Minecraft의 슬라임과 슬라임볼 에셋을 사용합니다. 출처는 [CREDITS.txt](../CREDITS.txt)에 정리되어 있습니다.

## 공용 스탯과 성장

자신의 슬라임을 우클릭해 관리 화면을 엽니다. 이름 입력란에서 설정한 이름은 이름표처럼 슬라임 위에 표시됩니다. 따라오기와 대기 버튼으로 행동을 바꾸며, 채굴 슬라임에는 채굴 버튼·곡괭이 장착 칸 1개·가방이 추가됩니다.

| 스탯 | 기본값 | 포인트당 증가 | 역할 |
| --- | --- | --- | --- |
| 체력 | 16 | +4 | 최대 생명력입니다. 강화해도 현재 생명력을 회복하지 않습니다. |
| 공격력 | 2 | +1 | 공격 시 기본 피해량입니다. 채굴 동료는 자동 전투를 하지 않습니다. |
| 방어력 | 0 | +1 | Minecraft 기본 갑옷 속성과 피해 감소 공식을 사용합니다. |
| 이동속도 | 0.30 | +0.015 | Minecraft 이동속도 속성입니다. |
| 작업속도 | 1.0배 | +0.1배 | 채굴 진행 속도 배율입니다. |
| 운반력 | 9칸 | +3칸 | 가방의 사용 가능한 칸으로, 최대 27칸입니다. |
| 지구력 | 100 | +20 | 연속 작업에 사용하는 최대 에너지입니다. |
| 사거리 | 3블록 | +0.25블록 | 채굴 동작을 실행할 수 있는 최대 거리입니다. |
| 탐지 범위 | 8블록 | +1블록 | 채굴 대상을 찾는 반경입니다. |

운반력은 6단계, 나머지 스탯은 20단계까지 강화합니다. 포인트 사용·이름 변경·관리 인벤토리는 주인만 조작할 수 있습니다. 스탯, 미사용 포인트, 활동 진행도와 현재 지구력은 월드 저장과 회수 후에도 유지됩니다.

첫 스탯 포인트는 블록 256개를 채굴하는 데 성공하면 획득합니다. 포인트를 얻을 때마다 다음 요구량이 64개씩 늘어나며 최대 4,096개입니다. 가만히 있기, 따라오기, 지시 변경과 회수·소환으로는 활동 진행도를 얻지 않습니다. 실패하거나 취소된 채굴도 진행도에 포함하지 않습니다.

## 채굴 슬라임

친근한 슬라임 아이템과 아무 곡괭이를 정해진 모양 없이 조합하면 **채굴 슬라임**을 만듭니다. 장착 곡괭이의 종류, 소모된 내구도, 이름과 마법 부여를 유지합니다. 회수한 친근한 슬라임도 저장 특성을 보존한 채 채굴 슬라임으로 전환할 수 있습니다.

채굴 슬라임은 램프가 달린 노란 광산모를 쓰고 장착한 곡괭이를 표시합니다. 새로 제작한 채굴 슬라임은 소환하면 채굴을 시작하며, 소환된 청크 안의 블록만 대상으로 삼습니다. 회수한 채굴 슬라임을 다시 소환하면 저장된 지시를 유지하고 새로 소환된 청크를 작업 구역으로 설정합니다.

탐지 범위 안에서 보이는 곡괭이 채굴 대상 블록을 찾습니다. 곡괭이 등급이 블록의 요구 조건을 충족해야 합니다. 블록 엔티티, 파괴 불가 블록, 청크 밖과 탐지 범위 밖 대상은 건너뜁니다. 먼 대상에는 접근한 뒤 사거리 안에서만 채굴합니다.

실제 장착 곡괭이로 파괴 속도와 결과를 계산하므로 행운과 섬세한 손길을 적용합니다. 내구성 마법을 포함한 일반 내구도 소모 규칙을 따릅니다. 곡괭이가 부서지거나 없으면 정지하며, 장착 칸에 새 곡괭이를 넣으면 다시 작업합니다.

채굴 결과는 가방에 직접 모읍니다. 결과 전체를 담을 수 없으면 블록을 그대로 남기고 곡괭이 내구도를 소모하지 않은 채 정지합니다. 가방을 비우거나 운반력을 강화하면 재개합니다. Shift+클릭으로 가방 아이템을 플레이어 인벤토리로 옮길 수 있습니다.

채굴 성공 1회마다 지구력 1을 소모합니다. 지구력이 바닥나면 초당 2씩 회복하며, 최대치의 25%가 되면 작업을 재개합니다. 대기·따라오기 등 채굴하지 않는 시간에도 지구력을 회복합니다. mobGriefing 게임 규칙과 Forge 블록 파괴 권한을 따릅니다.

## JEI

JEI는 선택 사항입니다. 설치하면 친근한 슬라임 조합법, 등록된 곡괭이별 채굴 슬라임 조합법과 동료 안내를 표시합니다. 채굴 슬라임 미리보기에는 해당 장착 도구가 반영됩니다. JEI 없이도 Slimic을 사용할 수 있습니다.
